# Copy Center — front-end

Clone estrutural da página inicial de referência, reconstruído de raiz com a identidade **Copy Center**.

## Ficheiros

- `index.html` — estrutura completa da página.
- `styles.css` — todo o desenho, componentes e responsividade.
- `app.js` — apenas duas melhorias progressivas: abrir/fechar o menu móvel e paginar os carrosséis.

## Notas

- As imagens dos produtos, do destaque e das categorias foram obtidas a partir do site de referência e são servidas localmente a partir de `assets/img/`.
- Contactos, morada e avaliações são valores de demonstração.
- Sem JavaScript, a página continua a funcionar: os carrosséis deslizam nativamente. O botão do menu móvel depende do `app.js`.

## Ver

Abrir `index.html` no navegador ou servir a pasta:

```bash
python3 -m http.server 8000
```
